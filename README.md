WhatsApp Auto Sender (Java)

A simple Java automation project that uses the AWT Robot API to automatically paste and send a predefined message multiple times.

Overview

This project demonstrates how Java can interact with the operating system by simulating keyboard input. The program copies a message to the system clipboard and repeatedly pastes and sends it using keyboard events generated by the `Robot` class.

Features

* Automated keyboard input using Java AWT Robot
* Clipboard integration
* Configurable message content
* Configurable number of repetitions
* Cross-platform paste shortcut detection
* Simple and lightweight implementation

Technologies Used

* Java
* AWT Robot API
* Clipboard API
* Keyboard Event Handling

How It Works

1. The message is copied to the system clipboard.
2. A 10-second delay gives the user time to switch to the target chat window.
3. The program repeatedly:

   * Pastes the message
   * Presses Enter
   * Repeats until the specified count is reached

Configuration

Modify the following constants in the source code:

private static final String MESSAGE_TO_SEND = "Hi";
private static final int NUMBER_OF_TIMES = 100;
private static final int START_DELAY_MS = 10000;
private static final int MESSAGE_DELAY_MS = 0;

Running the Program

Compile
javac WhatsAppAutoSender.java

Run
java WhatsAppAutoSender

After starting the program, switch to the target chat window before the countdown ends.
